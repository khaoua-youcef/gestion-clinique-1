#  Gestion de clinique médicale

##  Description
Ce programme en **langage C** permet de gérer les tickets des patients et le système d'observation d'une clinique. Il utilise des **structures** et la **manipulation de fichiers** pour sauvegarder les données.

##  Fonctionnalités
* Ajout d'un nouveau patient (nom, prénom, âge).
* Attribution d'un numéro de ticket.
* Recherche d'un patient par nom (en cours de développement).
* Historique des consultations.

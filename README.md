#  Gestion de clinique medicale

##  Description
Ce programme en **langage C** permet de gerer les tickets des patients et le systeme d'observation d'une clinique. Il utilise des **structures** et la **manipulation de fichiers** pour sauvegarder les donnees.

##  Fonctionnalites
* Ajout d'un nouveau patient (nom, prenom, age).
* Attribution d'un numero de ticket.
* Recherche d'un patient par nom (en cours de developpement).
* Historique des consultations.
